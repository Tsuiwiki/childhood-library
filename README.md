# 童年书房 · Childhood Library

面向儿童的数字文化资源库，聚合并整理儿童文学、经典儿歌、古诗词和英文儿歌，提供自动发现与采集、标准化、去重、版权审核、人工校对和网站展示能力。

> **项目原则：内容质量优先、来源可追溯、版权先行、人工审核后发布。**
>
> 本仓库只存放软件代码、设计文档、元数据规范和必要的测试样例。未经明确授权，不提交受版权保护的文学正文、歌词、录音、绘本图片或其他媒体文件。

## 项目目标

- 建设结构化、可检索、可持续维护的儿童文化资源目录。
- 通过开放 API、开放数据集、RSS 和明确允许的来源自动发现资源。
- 将不同来源的数据转换为统一作品模型，保留来源、版本和处理记录。
- 使用 AI 辅助分类、摘要、字段补全和质量检查，不让 AI 自动决定版权状态。
- 建立版权与内容审核流程，审核通过后才允许公开展示。
- 为文学阅读、诗词学习和歌曲播放提供统一的网站体验。

## 首期内容范围

1. 儿童文学：童话、寓言、民间故事、儿童小说、儿童诗歌。
2. 经典儿歌：中文儿歌、传统童谣及授权歌曲目录。
3. 古诗词：唐诗、宋词、元曲及儿童诗词启蒙。
4. 英文儿歌：Nursery Rhymes、字母歌、数字歌、动物与自然主题歌曲。

## 技术路线（拟定）

| 层次 | 首选方案 |
| --- | --- |
| Web 前台 / 管理后台 | Vue 3、TypeScript、Vite |
| API | Python、FastAPI、Pydantic |
| 主数据库 | PostgreSQL |
| 采集与解析 | Python、HTTPX、BeautifulSoup（遵守来源规则） |
| 任务队列 | Celery + Redis（MVP 可先简化） |
| 媒体存储 | S3 兼容对象存储；仅保存获准使用的媒体 |
| 部署 | Docker Compose、Nginx |

技术选型允许在 MVP 实施中调整，避免过早引入微服务和复杂基础设施。

## 开发状态

当前处于 **Phase 0：项目定义与基础设计**。当前提交建立产品边界、技术方案和数据治理规范；尚未包含可运行的前后端程序或已核实可转载的内容数据。

## 基本原则

- 默认不抓取登录后内容、付费内容、受技术限制的内容或明确禁止自动访问的页面。
- 尊重 robots.txt、网站服务条款、API 使用政策、速率限制和授权范围。
- “可访问”“公版作品”“开放许可”“允许转载”不是同一个概念，必须逐项核实。
- 作品正文、译文、歌词、插画、录音和编曲分别记录权利状态。
- 待确认或授权不明的内容只进入内部审核队列，不公开展示、不分发媒体文件。
- 保留原始来源、采集时间、版本、转换记录和审核轨迹。
