## 0. 结构说明

按上级方案 §8 的三大支柱分配：

| 内容支柱 | 目标数量 | 本清单来源 | 说明 |
|---|---:|---|---|
| 中国经典 | 55 | 现有《经典儿童歌曲候选目录》中国 50 条 + 补 5 首 | 按八个专题重新归类 |
| 世界经典 | 30 | 现有英文 50 条中精选 | 剔除冷门历史采录碎片与占位条目 |
| 优秀原创 | 15 | 方向框架（暂不填具体曲目） | 待通过编辑评审与授权路径核验后填充 |
| **合计** | **100** | | 候选数，非可播放数 |

**与现有候选目录的关系**：本清单在 `CLASSIC_SONGS_CATALOG.md` 基础上精修——中国 50 条全部保留并重新归类，世界 50 条**精选出 30 条**。原目录仍作为「发现清单」继续使用，本清单是它的下游「种子库视图」。

> **口径说明**：本清单严格遵循上级方案 [MUSIC_LIBRARY_PLAN_V1.md](MUSIC_LIBRARY_PLAN_V1.md) §8 与 §13.1 的 100 首目标：**中国经典 55 + 世界经典 30 + 优秀原创 15 = 100 首**。世界经典从现有 50 条中精选 30 条，历史语境敏感与多语言冷门采录条目标注「待审查」，作为候选池而非首播池。

**版权状态沿用原目录**，不做任何升级或降级：`candidate` = 候选待核验，`source_found` = 已发现来源待核验，`rights_pending` = 权利待核验。所有曲目当前均不得视为已获转载授权。

## 3. 优秀原创（15 首，方向框架）

按上级方案 §2 与 §8，优秀原创要求「通过编辑评审且授权路径清楚」。本阶段**不填充具体曲目**，先确立方向框架，待与创作者、机构建立可追溯授权后逐首填入。

| 方向 | 说明 | 授权要求 |
|---|---|---|
| 当代原创儿童歌曲 | 尊重儿童视角、创作质量过关 | 词曲作者明确授权 |
| 独立音乐人作品 | 自然主题、童真表达 | 可追溯书面授权 |
| 自然主题音乐 | 鸟鸣、风声、雨声与音乐结合 | 录音与编曲权利清晰 |
| 儿童音乐启蒙作品 | 引导聆听、非训练化 | 授权范围覆盖目标用途 |
| Childhood Library 原创音乐计划 | 项目自创或委托创作 | 底层作品权利清晰 |

> 原创 15 首当前为**占位框架**，不纳入「已入库」统计；待完成编辑评审与授权核验后，逐首补入并更新状态为 `authorized` 或按实际核验结果标记。
