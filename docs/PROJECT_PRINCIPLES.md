# Childhood Library 顶层设计原则

- 文档状态：Project Principle
- 版本：1.0
- 适用范围：整个 Childhood Library，包括音乐馆、故事馆、诗词馆及未来新增内容馆

## 1. 项目定位

Childhood Library 首先是一个面向儿童文化的**研究、发现、采集、整理与学习项目**，其次才是面向儿童和家庭提供阅读、聆听与欣赏服务的资源产品。

我们希望持续发现和整理中国及世界优秀的儿童文化成果，建立可追溯、可比较、可持续扩充的文化资源档案。项目不以“当前是否能够公开播放、转载或展示”作为判断作品是否值得研究和登记的前置条件。

## 2. 核心原则：先研究采集，再判断使用

**版权状态未知，不等于没有研究价值；暂时不能公开使用，不等于不应该收录研究线索。**

研究采集阶段应优先考虑：
- 文化与历史价值：作品是否具有时代、地域、民族或文化代表性。
- 文学与艺术价值：语言、旋律、叙事、审美和艺术表现是否值得研究。
- 教育与启蒙价值：是否有助于儿童接触语言、自然、社会、历史与想象世界。
- 资料价值：是否能补充版本、作者、演唱者、译者、出处、传播史等信息。
- 多样性：兼顾中国与世界、经典与当代、城市与地方、正式出版与民间口传。

不得仅因权利信息尚未核实，就从研究候选目录中排除有价值的作品。

## 3. 适用内容范围

本原则适用于所有儿童文化内容，不限于儿歌：

- **儿童音乐**：经典儿歌、传统童谣、地方童谣、校园歌曲、古诗词谱曲、民族音乐、世界儿童歌曲及优秀原创。
- **儿童故事与文学**：神话、传说、民间故事、童话、寓言、儿童小说、绘本作品、儿童文学经典及不同译本、改编本。
- **儿童诗歌与诗词**：古典诗词、儿童诗、民间歌谣、世界诗歌、不同译注与朗诵版本。
- **其他儿童文化**：戏剧、曲艺、语言游戏、传统节日文化、自然与科学启蒙内容等。

不同内容类型可以拥有独立的专业标准和字段，但应遵循统一的研究采集与使用审核原则。

## 4. 双层架构：研究资源库与儿童使用层

### A. 研究资源库（Research）

用于发现、登记、研究和维护候选作品及其版本线索。

可以登记：
- 版权状态未知、待核验或权利复杂的作品候选。
- 不同年代、地域、语言、演唱者、讲述者、译者和改编者的版本。
- 官方平台、出版社、图书馆、档案馆、学术资料、视频网站及其他公开页面的来源线索。
- 个人上传内容作为待核验的研究线索。
- 作品背景、版本差异、文化背景、审美分析和研究笔记。

研究记录应尽量保留作品身份、版本描述、来源名称、发布者、原始 URL、发现日期、访问日期和核验状态。优先保存必要元数据与原始来源链接，而不是复制第三方内容。

### B. 儿童阅读与使用层（Library）

用于面向儿童和家庭提供经过编辑整理的内容体验。

资源进入具体使用场景前，再根据作品、版本、内容资产、使用方式、地域和平台规则核实：
- 展示作品介绍或目录信息；
- 展示作品正文、歌词、译文、注释或插画；
- 跳转原始来源；
- 嵌入第三方播放器；
- 站内播放、下载、转载或分发。

不同使用方式分别判断。允许登记研究线索，不代表允许公开正文、复制媒体、嵌入播放或再分发。

## 5. 版权与来源的边界

版权审核不是研究采集的入口门槛，而是进入具体公开使用场景前的必要判断。

同时，内部研究也不意味着可以忽略适用法律、网站服务条款、访问限制和个人数据保护要求。项目应：
- 优先使用公开、合法可访问的来源和官方接口。
- 尊重 robots.txt、服务条款、API 政策、速率限制、登录与付费边界。
- 不绕过访问控制，不规避平台限制。
- 默认只登记必要元数据、研究笔记和原始链接；不因“内部研究”而默认下载、缓存、镜像、去水印或转存第三方媒体。
- 对个人上传内容不推定上传者拥有作品、表演、录音、译文或画面等全部权利。
- 对研究材料的团队共享、摘录、截图或保存，结合来源许可与适用规则单独评估。

## 6. 统一状态模型

研究进度、权利状态、内容质量和访问方式必须分开管理：

| 维度 | 示例状态 | 回答的问题 |
| --- | --- | --- |
| research_status | discovered / researching / reviewed / rejected | 研究到哪一步？ |
| rights_status | unknown / pending / verified / restricted / revoked | 权利核验到哪一步？ |
| quality_status | unreviewed / suitable / needs_context / unsuitable | 内容是否符合项目质量定位？ |
| access_method | source_link / official_embed / licensed_media / own_original / none | 当前允许采用什么访问方式？ |
| publication_status | draft / pending_review / approved / published / withdrawn | 是否可以进入公开层？ |

研究完成不等于版权已确认；版权确认不等于内容质量审核通过；内容适合儿童也不等于获得公开传播许可。

## 7. 内容质量与文化审美

项目不以数量作为唯一目标。应重视作品本身的艺术质量、语言质量、文化背景和长期价值：
- 不把儿童文化简化为低龄化、娱乐化或流量化内容。
- 不把所有作品都要求为欢快、热闹或强刺激。
- 尊重不同文化、时代、地域和艺术表达。
- 记录作品的历史背景、创作背景、传播脉络与版本差异。
- AI 可以辅助发现、分类、摘要和比对，但重要事实、来源和权利结论须有依据并经人工复核。

## 8. 从研究到公开的工作流程

1. 发现作品或来源线索。
2. 登记候选作品与来源，不因权利未知而直接丢弃。
3. 核实作品身份、作者、版本、年代和文化背景。
4. 进行内容质量与儿童适宜性评估。
5. 独立核验正文、译文、插画、录音、视频等各项权利。
6. 根据目标使用方式选择外链、官方嵌入、授权媒体或仅保留目录信息。
7. 人工审核后发布；授权变化、来源变化或投诉发生时重新评估。

## 9. 长期目标

逐步形成一座具有研究深度和文化审美的儿童文化图书馆：既能让家庭发现优质内容，也能沉淀作品来源、历史版本、文化脉络和研究成果。**先尽可能完整地发现与理解儿童文化，再审慎决定每项资源可以如何被使用。**
