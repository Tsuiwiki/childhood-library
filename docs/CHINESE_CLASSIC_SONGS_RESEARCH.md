# 中国经典儿童歌曲研究与资源采集

- 版本：v0.1
- 更新日期：2026-11-19
- 状态：第一轮公开资料发现；曲目为研究候选，部分元数据已由机构资料交叉核验
- 范围：中国近现代经典儿童歌曲、传统童谣及适合儿童欣赏的经典少儿歌曲
- 排除口径：不以短视频热度、网络洗脑度、近年口号式/流量型低幼歌曲作为核心收录依据

> 本文遵循 Childhood Library 顶层原则：**先研究采集，再判断使用**。本目录记录作品身份、创作背景、资料来源和可访问资源线索；不代表第三方歌词、乐谱、录音已获转载或站内播放授权。

## 1. 本项目所说的“中国经典儿歌”

本轮以《让我们荡起双桨》作为审美参照，重点寻找具有以下特征的作品：

1. 旋律优美、自然、流畅，有清晰的旋律线条，不依赖高密度音效或机械重复。
2. 歌词有文学性和画面感，能够描写自然、季节、动物、田野、亲情、童年生活或想象世界。
3. 具有儿童视角和儿童情感，不是单纯把成人口号改写成儿童歌词。
4. 在不同年代持续传唱，或在中国儿童音乐史、电影音乐、校园音乐和民间音乐中具有代表性。
5. 适合家庭聆听和反复欣赏，不仅仅适合舞台表演或课堂齐唱。

### 明确区分的内容

- **核心收藏**：近现代经典儿童歌曲、抒情儿童歌曲、自然与生活题材歌曲。
- **文化收藏**：传统童谣、地方方言童谣、摇篮曲、游戏歌、民歌及少数民族儿童歌曲。
- **扩展收藏**：经典动画、电影、少年歌曲中具有较高音乐价值的作品。
- **暂不作为核心**：近年短视频热曲、以口号和动作编排为主的低幼歌曲、单纯依靠重复和音效吸引注意力的作品。

“经典”不等于所有年代作品都必须入选；“传唱度高”也不自动等于音乐质量高。最终须经过具体版本的聆听评审。

## 2. 重要书目和资料入口

### 2.1 《中国儿童歌曲百年经典》

- 出版信息：上海音乐出版社，四卷本；相关出版介绍称收录1900—2015年间具有代表性和持久影响力的儿童歌曲500首。

## 4. 传统童谣与地方音乐：独立建档

传统童谣与现代创作歌曲的资料结构不同。口传作品经常存在同名异文、方言差异、地区差异和采录者差异，不能随意指定一个“唯一作者”。

首批地方研究入口：

| 地区/类型 | 研究方向 | 公开来源 |
|---|---|---|
| 北京童谣 | 生活童谣、游戏歌、语言节奏和地方文化 | [中国非物质文化遗产网：北京童谣](https://www.ihchina.cn/project_details/12315.html) |
| 闽南童谣 | 闽南语韵律、摇篮曲、问答歌、游戏歌 | [中国非物质文化遗产网：闽南童谣](https://www.ihchina.cn/project_details/12316.html) |
| 绍兴童谣 | 地方方言、历史文献、民俗和传唱版本 | [中国非物质文化遗产网：绍兴童谣](https://www.ihchina.cn/project_details/12317.html) |
| 河南童谣 | 《筛罗罗》《王大娘钉缸》《月奶奶》等音像线索 | [平顶山学院童谣音像库](https://wxy.pdsu.edu.cn/wxzl/mswhsjk/tyyxk.htm) |
| 泰顺童谣 | 方言录音、文本、插画和田野采录方法 | [国家档案局：泰顺童谣档案整理](https://www.saac.gov.cn/daj/c100206/202602/3dc1884ecf2f4c389507661cea7557ea.shtml) |

地方童谣每条记录至少应包括：采录地、方言、采录者、讲述/演唱者（若公开）、采录时间、文本异文、音频出处、民俗背景。没有可验证作者时，作者字段应为空或标记“民间口传”，不虚构个人署名。

## 7. 版本级审美评审

每首作品至少挑选2个不同录音版本进行对比。建议从以下方面打分（1—5分）：

| 维度 | 评审问题 |
|---|---|
| 旋律美感 | 旋律是否自然、舒展、优美，是否值得反复聆听？ |
| 歌词文学性 | 是否有画面、意境、故事和儿童视角？ |
| 编曲质量 | 是否克制、清晰，是否避免无必要的音效堆叠？ |
| 演唱表现 | 是否自然、准确、清楚，是否避免喊唱和刻意卖萌？ |
| 录音品质 | 人声、伴奏是否平衡，是否有明显失真或过度处理？ |
| 适龄性 | 歌词和表达是否适合儿童及家庭共同欣赏？ |
| 耐听性 | 是否适合长期重复聆听？ |

评审对象是“具体录音版本”，不是笼统给作品打分。若同一作品有历史原声、童声合唱、成人翻唱和现代重编版本，应分别建档。

## 9. 版权与资源使用边界

- 作品、歌词、译词、曲谱、改编、表演、录音和封面分别核验，不能把“歌曲是经典”当作授权依据。
- 公开试听页面只作为原站访问入口；未经授权不下载、不缓存、不镜像、不重新上传音频。
- 图书馆馆藏或校内播放资源不等于允许站外传播。
- 正版出版物的目录信息可用于书目发现；不能据此复制整本歌词或乐谱。
- 传统童谣可能存在公版文本，但现代采录录音、整理版本、编曲和演唱仍需独立判断。
- 对权利不明条目，先保存必要元数据、出处和来源链接，保持 `rights_pending`。
