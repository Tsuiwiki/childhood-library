# 产品需求文档（PRD）

- 项目：童年书房（Childhood Library）
- 文档状态：Draft
- 版本：0.2
- 范围：首期免费公共儿童文化数据库、教育服务及内容管理后台

## 1. 产品定位

Childhood Library 首先是儿童文化研究、发现、采集、整理与学习项目，其次才是面向儿童及家庭的数字文化资源产品。项目覆盖儿童音乐、故事文学、诗歌诗词及其他儿童文化内容。

遵循“先研究采集，再判断使用”：版权状态未知不构成有价值作品进入内部研究目录的前置障碍；但研究登记不等于获得复制或公开传播许可。面向儿童家庭展示正文、译文、图片、音频、视频，或提供嵌入、下载和分发前，必须按具体作品、版本、资产、地域和使用方式核验。

完整原则见 [项目顶层设计原则](PROJECT_PRINCIPLES.md)。

平台同时定位为免费供大众及教育使用、以普及教育和传统文化传承为目标的公共数字文化数据库，服务大众、家庭、教师与教育机构。

**收录规则：目录先行、内容后审。** 可发现的资源可以进入候选目录并公开必要的基础元数据与合法来源链接；正文、歌词、译文、插画和音频等具体内容不因可访问或教育用途而自动公开。

## 2. 目标用户

- 大众与家庭阅读者：免费查找适龄故事、诗词、歌曲和传统文化资料。
- 教师与教育机构：发现课堂、阅读活动及传统文化教育所需的作品目录与合规资源。
- 内容编辑 / 管理员：整理作品、核对来源、维护分类与专题。
- 资源研究与维护人员：维护信源、采集任务、权利证据、使用条件和内容版本。

首期不建设社交社区，不开放儿童用户之间的互动。

## 3. 首期内容范围

### 3.1 文学故事馆
- 中国神话与传说、中国民间故事
- 世界经典童话、世界民间故事
- 中国与世界寓言、儿童文学经典
- 当代原创故事与绘本
- 故事作品、译本、改编本、插画和朗读资源分层管理
- 详细内容规划见 [儿童故事馆建设方案](STORY_LIBRARY_PLAN_V1.md)

### 3.2 经典儿歌馆
- 中文儿歌与传统童谣
- 游戏、自然、季节、生活主题歌曲
- 研究目录可登记权利未知的歌曲、童谣及不同版本线索；公开展示歌词、音频或嵌入播放前，按具体权利和使用方式审核

### 3.3 古诗词馆
- 唐诗、宋词、元曲及适合儿童接触的传统诗词
- 原文、作者、时代、出处、注释、释义及朗读资源分别管理
- 现代注释、译文和录音独立核验权利

### 3.4 英文儿歌馆
- Nursery Rhymes
- Alphabet / Counting Songs
- Animals / Nature / Daily Life / Bedtime 主题
- 英文文本、中文释义和录音分别记录来源及授权

## 4. 核心用户流程

### 访客
1. 进入首页。
2. 按内容馆、主题、语言或年龄范围浏览。
3. 搜索作品、作者或关键词。
4. 打开作品详情。
5. 阅读可公开内容，或跳转到经核验的官方播放页面。

### 编辑
1. 查看自动采集进入的待处理项目。
2. 检查作品身份、来源、重复项和版本。
3. 分别审核正文、翻译、插画、音频等资产的版权状态。
4. 校对内容、作者、分类、适龄信息。
5. 通过审核并发布，或退回、拒绝、仅保留外链。

## 6. 内容字段与展示要求

采集完整不等于已通过公开层审核；全文展示前仍须逐项记录权利状态与发布审批。

- 作品标题、别名、类型、语言、作者、时代 / 朝代。
- 简介、主题分类、标签、适龄建议及建议依据。
- 正文或可用内容版本；正文默认按完整篇章、全卷或全书录入，不以节选、梗概、导读或原创整理稿冒充正文。
- 来源链接、来源名称、采集时间和版本信息。
- 版权状态及对应证据。
- 相关作品与专题。
- 媒体资产及每项资产的授权状态。

适龄建议属于编辑辅助信息，不应呈现为医学或发展评估结论。

## 7. 非功能需求

- 安全：管理端鉴权、最小权限、密钥不入库。
- 隐私：尽量不收集儿童个人信息；首期不设置儿童账户。
- 可追溯：采集、修改、审核、发布均留有记录。
- 稳定：采集任务失败可重试，不影响前台访问。
- 可维护：采集器按来源适配器隔离，单一来源故障不影响其他来源。
- 无障碍：清晰排版、键盘可操作、图片提供替代文本。
- 性能：目录与详情页支持分页和缓存，媒体采用按需加载。

## 8. 首期不做

- 用户上传未经审核的故事、歌词、图片或音频。
- 评论、私信、公开投稿社区。
- 自动下载或镜像商业平台的歌曲和绘本。
- 自动将版权不明的内容改写后作为原创发布。
- 复杂推荐算法、个性化画像和儿童行为追踪。

## 9. MVP 验收标准

1. 四类内容均可通过统一模型录入和展示。
2. 作品可关联作者、分类、标签、来源和版权记录。
3. 待评审资源可通过公开接口提供基础目录与合法来源链接；待评审正文、插画、音频等具体内容不会出现在公开接口。
4. 版权状态可按作品正文及媒体资产分别管理。
5. 管理员可以审核、退回、拒绝和发布内容。
6. 搜索与分类浏览可正常工作。
7. 所有公开内容均能追溯到来源和审核记录。
