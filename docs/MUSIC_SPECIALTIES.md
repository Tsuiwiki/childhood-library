# 音乐馆八个专题 · 候选作品归类

> 依据《儿童经典音乐图书馆建设方案》§2.1 八个专题定义，对首批 100 首候选目录（CLASSIC_SONGS_CATALOG.md）进行策展归类。
> 专题可多选；此归类为策展视角，不替代作品类型、地区、语言等基础字段。

## 专题定义（规划 §2.1）

| 专题 key | 专题名 | 内容范围 | 编辑关注点 |
|---|---|---|---|
| childhood | 童年的歌 | 中国经典儿童歌曲、校园歌曲、童年记忆 | 区分儿童歌曲、校园歌曲与成人怀旧作品 |
| nature | 大自然的歌 | 春夏秋冬、花草树木、鸟兽、河流海洋 | 自然观察、画面感与旋律舒展度 |
| play | 游戏与伙伴 | 游戏歌、拍手歌、数数歌、问答歌 | 互动性、语言趣味与传统玩法 |
| lullaby | 月亮与摇篮曲 | 中国及世界各地摇篮曲、安睡音乐 | 温柔、克制、适合陪伴，不承诺助眠效果 |
| classical | 古典音乐的童年 | 儿童古典作品、适龄器乐小品、音乐故事 | 引导聆听，不把作品简化成"训练工具" |
| world | 世界的童谣 | 多语言童谣、地方儿童歌曲、民族音乐 | 保留原语言、文化背景和地域版本 |
| forgotten | 被遗忘的童谣 | 地方方言、口传童谣、历史采录 | 记录传承人、采录地点、异文和语境 |
| original | 新芽原创 | 当代原创儿童音乐 | 尊重儿童视角、创作质量与明确授权 |

## 归类规则（按 type/note 关键词）

- 摇篮曲 / 摇篮 → lullaby
- 古典 → classical（Brahms' Lullaby 等古典摇篮曲，兼顾 lullaby 可多选）
- 游戏 / 拍手 / 数数 / 问答 / 轮唱 / 绕口令 / 互动 / 动作 / 手指 → play
- 自然 / 动物 / 植物 / 田园 / 海洋 / 春天 / 季节 / 草原 / 叠句自然 → nature
- 地方童谣 / 北京童谣 / 绍兴童谣 / 闽南 / 历史童谣 / 口传 → forgotten
- 英文 / 西语 / 加勒比 / 希腊 / 民族（世界） → world
- 中国创作儿歌（校园/合唱/童年/节日/生活/家庭等） → childhood
- 当代原创 → original（本批暂无，占位）
