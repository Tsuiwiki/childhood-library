# 音乐馆设计：经典歌曲目录与播放资源管理

- 文档状态：Draft
- 版本：0.1
- 更新日期：2026-11-17
- 当前阶段：公共站点先建设歌曲目录和元数据，不开发公开站内播放器；内部原型支持有逐文件许可记录的开放示例，以及不上传、不发布的本地浏览器试听
- 长期定位：见 [儿童经典音乐资源库 V1.0 规划](MUSIC_LIBRARY_V1.md)（中国经典为根、世界经典为窗、优秀原创为未来）；本文负责播放资源与版权门禁的工程细节

## 1. 建设目标

Childhood Library 音乐馆定位为有编辑标准、有来源记录、有版权边界的儿童音乐文化目录，而不是音频搬运或短视频聚合站。

首期目标：
- 建立音乐研究库，允许记录尚未完成权利核验的候选作品和公开版本线索。
- 建立经典歌曲作品目录，整理标题、别名、地区、语言、类型、创作者和文化背景。
- 将歌曲作品与具体演唱/录音/视频版本分开管理。
- 将版权核验、内容审核和播放资源审核分开记录。
- 首期只提供经审核的外部正版页面链接；没有合适链接时只展示歌曲资料。
- 为后续官方嵌入播放器、授权音频站内播放预留数据结构，但不提前实现播放器。

## 2. 研究库与公开音乐馆分离

研究阶段与公开传播阶段采用不同门槛，不能用面向公开播放的版权门禁阻断内部作品发现。

### 2.1 音乐研究库 Research

用于内部编辑和研究。可以记录 Bilibili 等平台上的个人上传、官方上传、历史演唱、翻唱、动画和不同改编版本，作为作品与版本研究线索。版权未知或待核验不妨碍登记。默认只保存必要元数据和原始页面 URL，通过原平台访问，不下载、缓存、镜像或转存第三方媒体；同时遵守平台条款和适用法律。

建议研究记录字段：
- research_status：discovered / researching / reviewed / rejected。
- source_platform、source_url、source_title、publisher_or_channel、published_at、discovered_at。
- version_description：历史演唱、现代翻唱、动画版、纯音乐、合唱等描述。
- research_notes、editorial_assessment、verification_questions。
- rights_status：unknown / pending / verified / restricted / revoked。
- access_method：source_link / official_embed / licensed_audio / own_original / none。

个人上传资源可作为研究线索，不应一概排除；但上传者不一定拥有作品、表演、录音和视频的完整权利，不能自动视为授权来源。

### 2.2 儿童音乐馆 Library

面向儿童和家庭的公开策展层。可以公开经过审核的作品档案和文化介绍；媒体播放入口必须根据具体版本和使用方式另行审核。版权未知的媒体不嵌入、不托管；必要时只展示经审核的作品元数据，不显示播放入口。

### 2.3 状态相互独立

research_status 表示研究进度，rights_status 表示权利信息，access_method 表示访问/播放方式。三者不得合并成单一审核状态。研究完成不等于权利已核实；权利未知不妨碍内部研究，但不允许自动启用播放。

## 3. 内容与播放资源分离

核心原则：**歌曲作品不是某一个视频，也不是某一份录音。**

同一首歌可能有多个演唱者、编曲、录音、MV 或平台视频；同一个作品的不同版本可能有不同权利人和使用条件。因此建议分为三层：

1. songs / works：歌曲作品本身，例如《让我们荡起双桨》。
2. song_versions：具体版本，例如某合唱团演唱版、钢琴伴奏版、某次历史录音或某个 MV。
3. playback_resources：承载该版本的播放资源，例如 Bilibili 视频、音乐平台官方页面、获授权的站内音频文件。

一个作品可以关联多个版本，一个版本可以关联多个播放资源。播放资源更换或失效，不应影响作品元数据。

## 4. 首期歌曲资料字段

建议每首歌至少记录：

| 字段 | 说明 |
| --- | --- |
| song_id | 稳定 ID，例如 CN-C01 |
| title / aliases | 标题与别名 |
| region / language | 地区与语言 |
| category | 自然、童年、温暖、世界之歌等主题 |
| song_type | 童谣、摇篮曲、创作儿歌、民歌、古典作品等 |
| lyricist / composer | 作词、作曲；未知时留空 |
| arranger | 编曲者（针对具体版本） |
| description | 简短作品介绍 |
| historical_context | 创作背景、地域或文化说明 |
| source_records | 元数据来源与核验日期 |
| lyrics_rights_status | 歌词权利状态 |
| composition_rights_status | 词曲/旋律权利状态 |
| publication_status | 草稿、待审、已通过、已发布等 |

不要求首期录入完整歌词。未取得相应权利时，不复制完整歌词、乐谱或歌词图片。

## 5. 播放资源字段

每个播放资源独立记录：

| 字段 | 说明 |
| --- | --- |
| resource_id | 播放资源 ID |
| song_id / version_id | 关联作品和具体版本 |
| platform | bilibili、music_platform、official_site、self_hosted 等 |
| resource_type | external_link、official_embed、licensed_audio |
| resource_url | 官方页面或播放地址 |
| platform_video_id | 平台视频 ID，例如 Bilibili BV 号 |
| embed_url | 经核验后使用的官方嵌入地址 |
| recording_performer | 演唱者/表演者 |
| recording_label / recording_year | 发行方、录音年份（已知时） |
| recording_rights_status | 该录音/视频的权利状态 |
| platform_terms_checked_at | 平台条款核验日期 |
| embed_allowed | 平台是否允许站外嵌入 |
| embed_enabled | 是否通过人工审核并启用嵌入 |
| fallback_url | 嵌入不可用时的原站链接 |
| review_status / review_notes | 内容和资源审核结论 |

embed_enabled 默认必须为 false。不能仅凭视频页面可访问或 iframe 能加载，就将其改为 true。

### 5.1 内部原型本地试听（非发布）

内部审核原型可以提供仅保存在审核人员当前浏览器中的本地音频选择、试听、替换和移除功能，但必须同时满足：

- 音频由审核人员从本机选择，只写入浏览器 IndexedDB，不上传到项目服务器、对象存储或第三方服务。
- 页面持续标明「内部本地试听、不上传、不发布」，不将本地文件显示为公开播放资源。
- 本地试听不改变作品、歌词、旋律、编曲、表演或录音的权利状态，也不构成授权证据。
- 清除浏览器数据或移除条目后，原型不再保留该音频；不得将内部音频库直接部署为公开资源。
- 未来转为站内托管或公开发布时，仍须按上述门禁重新核验具体录音及底层作品权利。

### 5.2 内部原型开放许可示例（非公开发布）

为评估真实音频播放体验，内部原型可以附带少量许可明确的示例文件，但必须同时满足：

- 逐文件核对具体录音来源页、作者、下载地址、许可证和获取日期，并记录文件大小及 SHA-256；不得仅凭“传统童谣”或“免费下载”认定录音可复用。
- 示例保存在 `design-demos/audio/`，仅供内部原型体验，不自动播放；页面运行时不请求第三方音频服务。
- 卡片和详情持续标明「开放示例」及具体许可证，与 IndexedDB 中的「内部本地音频」分开呈现；详情提供录音来源和许可证全文链接。
- 歌词须区分「录音对应唱词」与「传统歌词参考」，不得补写录音中未出现的人声内容；五线谱须标明调性、拍号、小节数及简化记谱边界，不冒充录音原调或完整编曲。
- 歌曲封面优先使用项目原创素材并记录生成源文件；开放示例的歌词、谱面和封面只提供给资料完整的具体条目，不为其他候选条目自动补全或虚构。
- 示例许可只覆盖对应具体文件，不改变候选作品的核验状态，也不代表同曲目的其他录音已获授权。
- 转为公开发布前仍须复核目标地域、实际用途、署名及相同方式共享等义务；如需改编音频，应另外记录变更并遵守对应许可。

### 5.3 内部权利待核验歌曲示例（非发布）

根据 2026-11-17 的内部原型需求，《让我们荡起双桨》《小燕子》《歌声与微笑》可以直接在本地原型展示完整歌词、原创封面和经典人声录音，但必须遵守以下边界：

- 条目在卡片、详情和播放器中持续标明「内部歌曲示例 · 权利待核验」，不得混入开放许可筛选语义或显示为已授权。
- 音频使用公开页面可访问的经典人声版本，并逐文件记录演唱者、来源页、实际文件地址、大小与哈希；公开可下载不等于开放许可。完整歌词须作为 MusicXML `<lyric>` 数据写入谱面，并由 Verovio 渲染在 SVG 音符下方；多段歌曲保留所有段落，中文按字、英文按音节对应。若为了展示完整唱词而细分教学音符，必须明确说明，不冒充录音原调、逐字节奏或完整合唱总谱。
- 目录中的 `rights_pending` 状态不因内部展示而改变；该模式不构成公开传播、正式发行或免除授权的依据。
- 转为公开发布、对外交付或部署到可公开访问的环境前，仍须完成词曲、歌词、谱面和具体录音的分层授权核验。

## 6. 版权与发布门禁

歌曲权利需要分层核验，至少区分：
- 歌词/词作；
- 曲/旋律；
- 译词、改编与编曲；
- 表演/演唱；
- 录音制品；
- MV/视频画面、封面及其他视觉素材。

外部链接、嵌入播放和站内托管是三种不同使用方式：
- **外部链接**：只保存必要元数据和指向原站的链接；优先使用权利人或官方平台页面，仍需遵守来源条款。
- **官方嵌入**：必须同时核验具体视频/录音的权利状态、平台嵌入规则和内容适龄性。平台提供 iframe 技术能力不等于授予歌曲版权。
- **站内托管**：只有在取得覆盖目标地域、用途、期限及传播方式的必要授权，或确认作品与录音均可合法使用后，才允许上传和播放。

任何权利状态为 pending、restricted 或授权范围不清的媒体，不得站内托管或嵌入播放。可以在政策允许范围内保留基础元数据供内部审核。

## 7. Bilibili 等平台嵌入策略（后续阶段）

后续可评估 Bilibili 官方站外播放器，但采用平台提供的正规嵌入方式，不下载、代理、缓存或重新分发视频。

启用前检查：
1. 视频来自权利人、官方账号或有明确授权的发布者。
2. 歌曲词曲、具体录音/表演及视频素材的权利状态已经审核；必要时取得许可。
3. 平台当前条款允许该视频站外嵌入，且没有登录、付费、地域或其他限制。
4. 视频内容适合儿童文化资源馆，不含不适龄广告、诱导内容或不合适的推荐体验。
5. 页面提供原站打开入口；嵌入失败时优雅降级为外链。
6. 默认不自动播放；关闭弹幕及非必要互动；避免未经必要性评估就加载第三方脚本。
7. 记录平台条款核验日期、审核人、视频 ID 和复核状态；视频下架、权限变化或授权撤回时及时禁用。

第三方播放器可能设置 Cookie、收集设备信息或展示平台自己的推荐与界面。正式上线前应评估隐私告知、儿童用户体验和适用地区法规。

## 8. 音乐馆内容分类

建议首批采用四个编辑主题：
1. **自然之歌**：春天、花草、鸟儿、河流、大海。
2. **童年之歌**：游戏、伙伴、校园、成长。
3. **温暖之歌**：摇篮曲、亲情、友谊、陪伴。
4. **世界之歌**：中国民歌、世界童谣、多语言歌曲与古典音乐。

主题分类可以多选，不替代歌曲类型、语言和地区字段。

## 9. 建设阶段

### Phase M1：研究库与目录建设（当前）
- 使用现有《经典儿童歌曲候选目录》作为发现清单。
- 允许登记公开平台上的个人上传和官方上传版本作为研究线索；版权未知不阻断研究登记。
- 首批优先核验约 20 首歌曲的作品身份、创作者、地区、语言和可信来源。
- 为每首歌建立作品元数据；同名异文和不同地区版本分别记录。
- 版权状态未核实时保持 rights_pending，不把候选曲目描述成已获授权。
- 公共站点暂不开发播放器、不下载音频、不保存第三方视频；内部原型可按 5.1 节进行当前浏览器内的本地试听，并按 5.2 节附带少量逐文件许可清晰的开放示例，均不公开发布。

### Phase M2：外部正版链接
- 人工筛选官方或权利人发布的试听页面。
- 记录具体录音/视频版本和资源 URL。
- 检查链接有效性、来源可信度和儿童内容适宜性。
- 页面只展示外链，不承诺第三方页面的播放体验。

### Phase M3：官方嵌入播放器
- 先选少量权利与平台规则均清晰的资源试点。
- 通过平台官方 iframe / embed 接口嵌入。
- 实现 embed_enabled 审核开关、失败降级、第三方内容提示和定期复核。
- Bilibili 只是候选平台，不作为唯一或默认播放源。

### Phase M4：授权音频馆
- 与音乐人、唱片方、合唱团或权利人合作取得书面授权。
- 记录授权地域、期限、用途、署名和撤回条件。
- 仅对授权范围内的录音开放站内播放或下载。

## 10. 首期验收标准

- 候选目录中的歌曲可按主题、地区、语言和类型检索。
- 每首歌曲有稳定 ID、基本元数据和来源记录。
- 作品记录与录音/视频资源记录分离。
- 歌词、词曲、编曲、表演、录音及视频素材的权利状态可分别管理。
- 未核实资源不会显示站内播放或嵌入播放器。
- 资源失效或授权撤回时，可以单独下架播放资源而保留作品资料。
- 目录中的候选状态不会被误认为公开发布许可。
