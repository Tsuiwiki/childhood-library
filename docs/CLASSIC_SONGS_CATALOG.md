# 经典儿童歌曲候选目录（首批采集）

> 版本：v0.1 · 更新日期：2026-11-17  
> 当前状态：**候选目录 / 待逐曲核验**，不是可直接发布或下载的音频清单。

## 1. 建设目标与选曲原则

本目录优先寻找旋律自然、歌词有童趣、编曲不过度刺激、适合亲子共同聆听与演唱的作品。避免仅以短视频热度、节奏强度或“洗脑程度”作为收录标准。

初筛维度：

1. **旋律**：有清晰、自然的旋律线，容易记忆和哼唱。
2. **编曲**：优先原声乐器、简洁伴奏、自然音色；避免持续高密度音效和过度电子化处理。
3. **歌词**：有具体画面、自然观察、游戏趣味或温暖情感；避免成人化表达、强行说教和不适宜内容。
4. **演唱**：吐字清晰、音域适中、不过度喊唱或刻意卖萌。
5. **文化价值**：保留地域童谣、民间游戏歌、摇篮曲和经典创作儿歌的多样性。
6. **耐听性**：适合反复聆听，而不是依赖夸张音效或重复刺激。

## 8. 本轮采集结论与优先级

### P0：先做作品元数据和合法试听入口

1. 中国：优先核对《让我们荡起双桨》《我们的田野》《小燕子》《春天在哪里》及北京、闽南、绍兴童谣的具体版本。
2. 英语：优先核对 Twinkle, Twinkle, Little Star、Mary Had a Little Lamb、Row, Row, Row Your Boat、Hush, Little Baby、All the Pretty Little Horses。
3. 美国民谣：以 Smithsonian Folkways 的曲目目录和 LOC 的历史采录作为发现入口，逐首确认作品身份与录音权利。

### P1：做版本级资料补全

- 每首歌建立独立作品记录；同名异文、方言版、现代改编版、不同录音版不能简单合并。
- 记录原始语言、地区、创作者、最早可考来源、采录者、版本说明和合法试听链接。
- 对民间口传曲目标记“来源版本待考”，不要虚构作者或年代。

### P2：人工试听与审美评审

每个候选版本按 1–5 分评估：

| 维度 | 评审问题 |
|---|---|
| 旋律美感 | 是否自然、流畅、有记忆点？ |
| 编曲克制 | 是否避免音效堆叠、过度电子音色和持续高刺激？ |
| 演唱自然 | 是否清晰、温和、不喊唱、不刻意装可爱？ |
| 歌词童趣 | 是否有想象力、生活感和儿童视角？ |
| 适龄性 | 是否存在恐吓、羞辱、成人化或不合适的表达？ |
| 耐听程度 | 是否适合长期、重复聆听？ |

建议首轮试听由至少两位审核者独立评分，并记录选用的**具体录音版本**，不能只给歌曲本身打一个笼统分数。

## 9. 逐曲采集字段模板

后续入库时，建议至少记录以下字段：

- `work_id`：稳定作品 ID，例如 `CN-C01`
- `title` / `aliases`：标题与别名
- `region` / `language`：地区与语言
- `category`：摇篮曲、游戏歌、动物、自然、民谣等
- `tradition_type`：oral_tradition / composed / adapted
- `creator`：词作者、曲作者、改编者；未知则留空
- `source_url` / `source_title`：来源及页面标题
- `source_accessed_at`：采集日期
- `lyrics_rights` / `melody_rights` / `arrangement_rights` / `recording_rights`：分层权利状态
- `recording_performer` / `recording_label` / `recording_year`：录音版本信息
- `listening_url`：合法试听或原站跳转链接
- `aesthetic_scores`：审美评审分项
- `review_status` / `review_notes`：人工审核状态和说明

## 10. 版权与采集红线

1. 不因“传统”“古老”“网上到处都有”就认定可转载。
2. 不把博物馆、图书馆或唱片网站上的试听音频下载后上传到本站。
3. 不采集付费、登录后、明确禁止自动访问或有技术访问限制的内容。
4. 对版权不清的作品只保存必要元数据和来源链接，状态保持 `rights_pending` 或 `link_only`。
5. 公版判断必须考虑目标发布地区；美国的公版期限判断不能直接套用于中国或其他国家。
6. 即使原作或旋律已进入公版，现代译词、改编、编曲、表演、录音和封面仍可能受到保护。
7. 后续若需自建播放曲库，优先采用明确允许再分发的开放许可录音、获得书面授权的录音，或自行制作且确认底层作品权利清晰的录音。
