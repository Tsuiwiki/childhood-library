- 版本：0.1

- [x] 明确产品范围与首期内容类型
- [x] 编写初版 PRD
- [x] 编写初版架构与数据模型
- [x] 定义采集流程与版权门禁
- [x] 建立候选信源清单
- [ ] 逐项核验首批信源的 API、服务条款和作品权利
- [ ] 确定软件许可证

## Phase 1：可运行的资源管理 MVP

- [ ] 初始化 FastAPI 项目
- [ ] 初始化 Vue 3 前端
- [ ] 建立 PostgreSQL 迁移
- [ ] 实现作品、作者、分类、标签 CRUD
- [ ] 实现来源与版权记录
- [ ] 实现草稿、待审核、通过、发布和下架流程
- [ ] 实现公开目录、详情和基础搜索
- [ ] 建立自动化测试与本地 Docker Compose

验收：可以手动录入四类资源，完成审核并公开展示。

## Phase 2：采集基础设施

- [ ] 定义 Adapter 协议
- [ ] 支持 CSV / JSON 导入
- [ ] 支持官方 API / 开放目录 Adapter
- [ ] 支持 RSS / Atom（来源政策允许时）
- [ ] 实现幂等、去重候选和任务日志
- [ ] 实现来源启停、速率限制和失败重试
- [ ] 建立采集监控指标

验收：新发现的资源只进入待审核队列，不会绕过审核直接发布。

## Phase 3：AI 辅助编辑

- [ ] 分类和标签建议
- [ ] 作者匹配候选
- [ ] 简介和释义草稿
- [ ] 内容格式与字段完整性检查
- [ ] 重复作品提示
- [ ] 记录模型、提示词版本和生成历史
- [ ] 人工确认 AI 输出

验收：AI 只提供建议，不改变版权状态和发布状态。

## Phase 4：多媒体与专题

- [ ] 合法图片资产管理
- [ ] 授权音频上传和播放
- [ ] 外部官方播放链接
- [ ] 诗词朗读和歌曲关联
- [ ] 专题合集
- [ ] 年龄与主题筛选优化
- [ ] 无障碍与移动端体验优化

验收：媒体资产有独立版权记录，授权失效可下架。

## Phase 5：运营与扩展

- [ ] 来源健康检查与定期复核
- [ ] 权利人投诉和下架工作流
- [ ] 数据备份与恢复演练
- [ ] 搜索引擎优化
- [ ] 贡献者和原创授权流程
- [ ] 运行指标和质量报表

## 首批种子目录目标（非发布承诺）

- 儿童文学：100 条作品目录
- 中文儿歌：50 条歌曲目录
- 古诗词：200 条目录
- 英文儿歌：50 条歌曲目录

上述数量是目录建设目标，不代表全部作品都能取得正文、歌词、图片或录音的转载许可。先建元数据目录，再按权利核验结果逐步开放内容。

## 每个阶段的 Definition of Done

- 需求和验收条件明确。
- 数据迁移可重复执行。
- 核心逻辑有自动化测试。
- 错误处理和日志可定位。
- 权限与版权发布门禁有效。
- 文档与示例配置同步更新。
