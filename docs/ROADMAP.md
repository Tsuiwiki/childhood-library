## 故事馆专项路线（并入 Phase 1–4）

- [ ] **S1 资源研究与目录**：优先核验中国经典与世界经典首批 30 条作品，建立 100 条候选目录；记录作品身份、版本、来源和待核验事项。
- [ ] **S2 故事档案与合法阅读**：复用统一作品、作者、来源和版权模型，补充文本版本关系与低干扰阅读器；仅发布权利状态清楚且审核通过的文本。
- [ ] **S3 插画与朗读资源**：分别管理插画、封面、朗读者、录音版本和播放资源；每项媒体独立核验权利。
- [ ] **S4 专题策展与文化扩展**：建设中国地方故事、民族故事和世界地区故事专题，推进原创作者及文化机构授权合作。

故事馆详细规划见 [儿童故事馆建设方案 v1.0](STORY_LIBRARY_PLAN_V1.md)。

## 首批种子目录目标（非发布承诺）

- 儿童文学：100 条作品目录
- 中文儿歌：50 条歌曲目录
- 古诗词：200 条目录
- 英文儿歌：50 条歌曲目录

上述数量是目录建设目标，不代表全部作品都能取得正文、歌词、图片或录音的转载许可。先建元数据目录，再按权利核验结果逐步开放内容。

## 每个阶段的 Definition of Done

- 需求和验收条件明确。
- 数据迁移可重复执行。
- 核心逻辑有自动化测试。
- 错误处理和日志可定位。
- 权限与版权发布门禁有效。
- 文档与示例配置同步更新。


## 音乐馆专项路线（并入 Phase 1–4）

- [ ] **M1 目录建设（当前）**：基于经典歌曲候选目录，优先核验约 20 首作品的身份、创作者、地区、语言和可信来源；保持未核验版权状态，不提供站内媒体。
- [ ] **M2 正版外链**：人工筛选权利人或官方发布的试听页面，记录具体录音/视频版本、链接、来源和审核信息。
- [ ] **M3 官方嵌入**：评估 Bilibili 等平台官方 iframe；逐条核验作品/录音权利、平台嵌入条款、儿童适宜性与隐私体验；默认关闭嵌入，审核后启用。
- [ ] **M4 授权音频**：与权利人合作取得书面授权，记录地域、期限、用途、署名和撤回条件，再开放站内播放或下载。

音乐馆首期验收：作品与录音/视频版本分离；播放资源独立管理；版权和审核状态分层；未审核资源不会显示嵌入播放器；资源失效时可独立下架。详见 [音乐馆设计](MUSIC_LIBRARY_DESIGN.md)。
