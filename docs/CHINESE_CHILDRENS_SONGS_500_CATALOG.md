## 1. 重要依据与范围

《中国儿童歌曲百年经典》（尤静波主编，上海音乐出版社，四卷）公开出版介绍称，收录1900—2015年间由大中华地区词曲作者创作、填词或译配、具有代表性和持久影响力的儿童歌曲500首。四卷时间范围分别为1900—1948、1949—1978、1979—1999、2000—2015。公开介绍还说明每首作品附有歌曲分析、演唱提示、和弦及相关文献线索，另有范唱和伴奏录音版本。

- [中国出版政府奖提名介绍：17张CD、500首曲目](https://sghexport.shobserver.com/html/baijiahao/2021/08/16/513802.html)
- [四卷套装及曲目目录公开页面](https://search.megbook.com.tw/mall/detail.jsp?proID=3265760)
- [第一卷目录公开页面](https://search.megbook.com.tw/mall/detail.jsp?proID=3265756)

**重要筛选原则：**这套500首目录是重要的历史书目基线，不是本项目的最终收录名单。特别是第四卷（2000—2015）包含一些偏当代流行、动画或低幼表达的作品，需要按用户确定的审美标准重新评审。不能因为入选这套书就自动进入核心收藏，也不能因为不符合核心审美就从研究史料中删除。

## 2. 目录状态定义

- `bibliography_candidate`：公开书目目录中可见，已记录标题；尚未核实作者、年代或版本。
- `metadata_verified`：至少有可靠来源核验了部分创作元数据。
- `audio_source_found`：找到具体演唱/录音版本的来源入口。
- `score_source_found`：找到具体简谱或五线谱的出版/馆藏入口。
- `aesthetic_review_pending`：尚未完成旋律、歌词、演唱版本的审美评审。
- `core_selected`：经过审美评审后进入核心收藏。
- `historical_reference`：作为音乐史或传播史资料保留，不作为核心儿童聆听推荐。
- `rights_pending`：具体歌词、曲谱、编曲、表演或录音的使用权尚未核实。

## 7. 逐首采集字段

每首作品建立独立作品档案，并将录音、乐谱、出版版本拆成子记录。

### 作品基本信息
- `work_id`、标准名称、别名、异名
- 作品类别：原创儿童歌曲 / 学堂乐歌 / 民间童谣 / 民歌改编 / 电影歌曲 / 动画歌曲 / 少年歌曲
- 词作者、曲作者、编曲者、译配者；不明则留空并标记待考
- 创作年代、首次发表、首次演出、关联电影/动画/出版物
- 语言、地域、主题、历史背景
- 证据链接及字段可信度

### 音频版本
- 演唱者、合唱团、唱片/专辑、出版社/厂牌
- 录音年代、发行年代、时长、编曲信息
- 来源链接、访问方式（可试听/馆藏/购买/不可访问）
- 录音权利状态和来源条款

### 乐谱版本
- 简谱/五线谱/钢琴伴奏谱/合唱谱
- 出版社、书名、版次、ISBN、页码、编配者
- 馆藏或出版来源链接
- 乐谱权利状态

### 审美评审
- 旋律美感、歌词文学性、儿童视角、编曲质量、演唱表现、耐听性
- 评审录音版本及评审理由
- 结论：核心收藏 / 文化收藏 / 扩展收藏 / 历史参考 / 暂不推荐

## 8. 500首采集的执行阶段

1. **目录完整性阶段**：逐卷获取并核对500首目录，建立唯一ID，处理同名、异名和重复作品。
2. **作品身份阶段**：逐首补齐词曲作者、创作年代、首发出处、作品类别；无法确认的字段保持待考。
3. **媒体资源阶段**：逐首寻找至少一个可靠音频版本入口；能找到时再补充历史录音、代表性演唱和伴奏版本。
4. **乐谱阶段**：逐首登记简谱/五线谱的正规出版物或馆藏线索，记录页码和版本。
5. **审美筛选阶段**：听具体录音、评具体版本，筛出真正符合项目审美的核心作品。
6. **使用权核验阶段**：作品、歌词、乐谱、编曲、表演、录音分开核验；公开可访问不等于允许下载、复制或站内播放。

建议每批完成25—50首，所有批次都保留来源和状态，不以“500条标题”冒充“500首资源采集完成”。
