# 儿童经典音乐资源库 V1.0 规划

- 文档状态：Draft
- 版本：1.0
- 更新日期：2026-11-18
- 定位决策：**C**（中国经典与世界经典并重，优先挖掘中国经典）

---

## 0. 定位

**Childhood Library · 儿童经典音乐图书馆**

> CHILDHOOD LIBRARY · CLASSICAL & CHILDREN'S MUSIC

**以中国经典为根，以世界经典为窗，以优秀原创为未来。**

它不是一个追求歌曲数量的儿歌网站，而是一个长期建设的儿童音乐文化档案馆。这是一个可以持续十年、二十年积累的项目——今天收录的歌曲，将来孩子长大以后仍然值得重新打开、重新聆听。

---

## 1. 三大内容支柱

三个支柱并不是平均分配。初期资源建设精力建议为：中国经典 55%、世界经典 30%、优秀原创 15%。这是启动阶段的资源投入建议，不是永久比例。

### 01 · 中国经典（核心支柱）

优先建设：

- 中国经典儿童歌曲
- 中国传统童谣
- 民歌与地方童谣
- 校园歌曲与时代经典
- 中国古典诗词音乐
- 中国民族器乐作品

### 02 · 世界经典（重要支柱）

- 英美传统童谣
- 欧洲经典儿童歌曲
- 世界各地摇篮曲
- 世界民族音乐
- 儿童古典音乐
- 经典动画与音乐剧作品

### 03 · 优秀原创（未来支柱）

- 当代原创儿童歌曲
- 独立音乐人作品
- 自然主题音乐
- 儿童音乐启蒙作品
- Childhood Library 原创音乐计划

## 2. 中国经典：七个专题

中国部分不能只收录大家熟悉的十几首儿歌，划分为七个专题：

| 专题 | 代表性研究对象 |
| --- | --- |
| 经典儿童歌曲 | 《让我们荡起双桨》《小燕子》《听妈妈讲那过去的事情》 |
| 传统童谣 | 《摇啊摇》《月亮走》《数鸭子》等 |
| 校园与童年 | 《童年》《外婆的澎湖湾》等 |
| 自然与四季 | 《春天在哪里》《小螺号》等 |
| 动物与生命 | 《小青蛙》《小白兔》等传统及原创作品 |
| 古诗词音乐 | 《春晓》《静夜思》等诗词谱曲作品 |
| 民族与地方音乐 | 各地童谣、民歌、民族器乐小品 |

**分类原则**：校园歌曲、儿童歌曲、成人创作的怀旧歌曲不应混为一谈。例如《童年》虽具有很强的童年记忆，但其创作视角和音乐定位与幼儿童谣不同——可以收录，但应准确分类，不按“幼儿童谣”处理。

---

## 3. 世界经典：建立真正的国际视野

世界部分不只是把英文儿歌翻译成中文，而是让孩子认识不同文化里的音乐。建议按国家和文化区域建立收藏。

| 国家/地区 | 重点收藏方向 | 代表性作品 |
| --- | --- | --- |
| 英国 | 传统童谣、游戏歌 | Twinkle, Twinkle, Little Star、London Bridge Is Falling Down |
| 美国 | 民间童谣、自然歌曲 | You Are My Sunshine、Home on the Range |
| 德国 | 古典儿童音乐、摇篮曲 | Brahms' Lullaby |
| 法国 | 传统童谣、儿童歌曲 | Frère Jacques |
| 日本 | 童谣、四季歌曲 | 七つの子、赤とんぼ |
| 意大利 | 民歌、旋律优美的经典作品 | 意大利传统歌曲及儿童音乐 |
| 俄罗斯及东欧 | 民间童谣、摇篮曲 | 传统民歌和儿童合唱作品 |

**特别专题：世界各地的摇篮曲。**

不同国家的母亲如何哄孩子入睡？不同语言如何表达温柔？不同文化如何描绘月亮、星星和夜晚？这会是一个很有文化特色的收藏系列。

美国国会图书馆（Library of Congress）的儿童歌曲资料尤其值得研究：它把儿童歌曲视为成人教给孩子的歌曲、儿童之间传唱的歌曲以及儿童自己创作的歌曲，并保存了大量历史录音资料。

## 4. 音乐编辑准则（独立审美标准）

不因为一首歌很流行，就认为它值得收录。

**Childhood Library · 音乐编辑准则：优美 · 自然 · 童真 · 耐听**

| 评审维度 | 编辑关注点 |
| --- | --- |
| 旋律美感 | 旋律是否自然、优美、有记忆点 |
| 童真表达 | 是否呈现儿童的好奇、想象和情感 |
| 歌词文学性 | 是否有诗意、画面和故事 |
| 音乐品质 | 演唱、编曲、乐器是否协调 |
| 文化价值 | 是否有历史、地域或艺术价值 |
| 耐听程度 | 多次聆听是否仍然有吸引力 |
| 年龄适宜性 | 是否适合对应年龄阶段 |

**核心编辑原则**：

> 不以刺激性作为吸引力，不以重复性作为记忆力，不以热度作为艺术价值。

- 不排斥节奏明快的歌曲，但避免过度密集的音效。
- 不排斥现代编曲，但不盲目追求电子音效。
- 不排斥简单的旋律，但简单不等于粗糙。
- 不排斥安静的歌曲，也不要求所有歌曲都让孩子兴奋。

目标是让孩子真正欣赏音乐，而不是仅仅被音乐吸引注意力。

## 5. 五层信源体系

不同层级承担不同任务。

| 层级 | 信息来源 | 主要用途 |
| --- | --- | --- |
| L1 | 国家级非遗、文化机构、地方文化馆 | 挖掘中国传统童谣 |
| L2 | 国家图书馆、音乐研究机构、历史档案馆 | 考证作品和历史 |
| L3 | 专业音乐出版社、音乐学院、作曲家资料 | 了解音乐品质和创作背景 |
| L4 | B站、音乐平台、唱片公司官方频道 | 寻找演唱及播放版本 |
| L5 | 独立音乐人、原创作者、国际音乐档案 | 发现优秀新作品 |

**重点信源**：

- **中国非物质文化遗产网（中国非遗数字博物馆）**：北京童谣、闽南童谣、绍兴童谣专题。这是中国传统童谣的重要研究入口；绍兴童谣尤其值得关注，资料介绍了大量地方童谣的历史和不同表现形式。
- **Library of Congress — Children's Songs**：研究历史童谣、民族音乐、历史录音及歌曲的文化背景。
- **Smithsonian Folkways**：研究世界民族音乐、传统音乐和文化档案组织方式；注意逐项核实录音使用权限。
- **中国国家图书馆**：用于历史文献、出版信息和书目线索。

**红线**：文化机构的目录和研究资料可以帮助发现作品，但不意味着其中的音频都可以拿来播放。

## 6. 歌曲档案：每首歌都有自己的历史

不要设计成简单的歌曲列表。一首歌是一个独立的文化档案，允许拥有多个演唱、演奏和视频版本。

**作品档案示例：《让我们荡起双桨》**

- 作词：乔羽
- 作曲：刘炽
- 创作背景：待完善的历史资料
- 音乐类型：儿童歌曲 / 校园经典
- 文化标签：童年、自然、集体记忆
- 音乐版本：版本 A（历史演唱）、版本 B（现代演唱）、版本 C（纯音乐演奏）
- 编辑推荐语：一首值得了解的中国经典作品……
- 档案状态：资料待完善
- 播放授权状态：待核实

**六张核心数据表**：`songs`（歌曲基础档案）、`creators`（作词、作曲、演奏者）、`recordings`（演唱、演奏、录音版本）、`media_sources`（视频及音频来源）、`rights_records`（版权和授权证明）、`collections`（专题、歌单、编辑精选）。

**关键：歌曲作品与具体录音版本必须分开。** 一首传统童谣可能有多个地区版本、不同歌词版本和不同演唱版本，不能把它们全部当成同一份音频资源。

**版权分层**：作品著作权、表演者权、录音制作者权和视听作品权利须分别判断。每个播放版本单独记录权利人、授权主体、许可平台和地区、是否允许嵌入/自行托管/下载、授权期限、证明文件和核实日期。

不要仅凭歌曲年代判定公有领域。例如中国自然人作品的相关财产权保护期通常为作者终生及死亡后五十年，但录音制品、表演和视听作品仍需分别判断。

## 7. 年龄推荐体系

四个层级，年龄只是推荐参考，不是限制。好的音乐可以陪伴孩子很多年。

| 年龄 | 阶段 | 内容倾向 |
| --- | --- | --- |
| 0–2 岁 | 感知与陪伴 | 温柔摇篮曲、自然音色、简单旋律、亲子哼唱 |
| 2–4 岁 | 发现与表达 | 动物歌曲、自然歌曲、节奏游戏、简单童谣 |
| 4–6 岁 | 想象与创造 | 故事歌曲、传统童谣、合唱、音乐游戏 |
| 6–12 岁 | 欣赏与文化 | 古典音乐、民族音乐、校园经典、世界音乐 |

## 8. 第一阶段：100 首精品种子库

不追求一开始就收几千首。先做一个质量足够高的 100 首种子库。

**首批规划分配**：中国经典 55 首、世界经典 30 首、优秀原创 15 首。

**执行步骤**：

1. 建立 100 首候选歌曲目录
2. 补充创作者和历史背景
3. 为每首歌寻找至少一个可信版本
4. 进行音乐审美评审
5. 核实作品及录音版权
6. 完成第一批可播放资源
7. 制作专题页面和编辑推荐

**实施节奏**：

| 阶段 | 工作内容 | 交付成果 |
| --- | --- | --- |
| P0 | 音乐标准、数据模型、信源体系 | 资源规范 |
| P1 | 中国经典采集 | 55 首候选 |
| P2 | 世界经典采集 | 30 首候选 |
| P3 | 原创音乐发现 | 15 首候选 |
| P4 | 版权审核和播放接入 | 第一批可播放资源 |
| P5 | 音乐图书馆前端 | 正式专题页面 |

## 9. 目标呈现形态

首页不应该像音乐平台一样堆满专辑封面，而更像一本打开的儿童音乐图书：

- **今日推荐**：一首值得慢慢听的歌曲。
- **中国经典**：走进中国童年的旋律。
- **世界音乐**：听见不同国家的童年。
- **自然之声**：鸟鸣、风声、雨声与音乐。
- **古典音乐**：认识音乐大师。
- **摇篮曲**：温柔的夜晚。
- **音乐故事**：认识歌曲背后的人和时代。

每首歌都有一篇自己的小档案，每个专题都有编辑的介绍。这样它不只是播放器，而是一个真正有知识、有审美、有历史积累的数字图书馆。

## 10. 特色栏目：被遗忘的童谣

专门挖掘：

- 各地正在逐渐消失的地方童谣。
- 老一辈人小时候传唱的歌曲。
- 不同方言中的儿童歌谣。
- 早期儿童音乐出版物。
- 老唱片、历史演唱和传统乐器演奏。

北京童谣、闽南童谣、绍兴童谣都值得进一步整理。非遗资料显示，童谣不仅有游戏歌、问答歌，还有摇篮曲、数数歌、谜语歌等丰富形式。这类资源可能不会成为热门歌曲，但有很高的文化保存价值——这是本项目最可能做出差异化、也最可能留下来的价值。

---

## 11. 三个长期原则

1. **宁缺毋滥**：100 首真正优秀的歌曲，胜过 10000 首粗制滥造的歌曲。
2. **尊重文化**：每首歌尽量保留创作者、历史、地域和版本信息。
3. **尊重版权**：收录作品不等于取得播放权，所有播放资源独立审核。

---

## 12. 与现有实现的关系

本规划是 Childhood Library 音乐资源库 V1.0 的**长期基础方案**，是现有 `MUSIC_LIBRARY_DESIGN.md`（播放资源与版权门禁）和 `CLASSIC_SONGS_CATALOG.md`（首批候选目录）的上层定位与选曲纲领。

- **边界不变**：现有 9 首可播放示例（含《让我们荡起双桨》《小燕子》《歌声与微笑》等内部经典录音）仍是内部原型试听、权利待核验，不因本规划改变状态，也不构成公开发布授权。
- **儿童音频的播放方式不变**：本地 IndexedDB 试听、开放许可示例与内部经典录音的播放边界维持现状。
