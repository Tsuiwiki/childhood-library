# 版权与内容审核政策

- 文档状态：Draft
- 版本：0.1

## 1. 目的

本政策用于降低儿童文化资源网站在作品正文、翻译、歌词、图片、音频及外链展示方面的版权风险。它是产品和工程操作规范，不构成法律意见；存在疑问时应寻求专业法律意见。

## 2. 基本原则

- 公开可访问不等于允许复制、存储或再发布。
- 作品进入公版不代表现代译本、注释、编曲、录音和插画也进入公版。
- 不同国家或地区的保护期限和例外规则可能不同。
- 每一种内容资产独立记录权利状态。
- 无法确认权利时，默认不公开正文或媒体，仅在合规前提下展示必要的基础元数据和来源链接。

## 3. 权利对象拆分

文学作品：
- 原作
- 翻译
- 改编
- 注释 / 赏析
- 插画 / 封面
- 朗读录音

歌曲：
- 词
- 曲 / 旋律
- 编曲
- 表演
- 录音制品
- MV / 视频
- 封面和宣传图片

古诗词：
- 古典原文
- 校勘版本
- 现代注释
- 白话译文
- 朗读录音
- 配图

## 4. 权利状态

| 状态 | 含义 | 默认公开策略 |
| --- | --- | --- |
| pending | 尚未核实 | 不公开受保护内容 |
| public_domain_verified | 已核实公版 | 按核验地区及依据发布 |
| open_license | 开放许可 | 按许可证条件发布 |
| authorized | 已获得授权 | 严格按授权范围发布 |
| link_only | 仅允许外链 | 仅展示允许的元数据和链接 |
| restricted | 禁止公开使用 | 不公开相关内容 |
| expired_or_revoked | 授权失效或撤回 | 停止展示并按政策处理存储 |

## 5. 发布门禁

公开发布前检查：
1. 作品身份和版本已确认。
2. 来源记录完整。
3. 正文、译文、图片、音频分别有权利记录。
4. 地域、用途、署名及有效期符合发布范围。
5. 内容审核通过。
6. 作品和媒体均未处于限制或撤销状态。

任何一项不满足时，不得通过公开 API 暴露相应受限内容。

## 6. 署名与许可证

- 按许可证要求展示作者、来源、许可证名称和链接。
- 对要求相同方式共享的许可，核实衍生内容是否满足条件。
- 对禁止商业使用或禁止演绎的许可，不得超范围使用。
- 保存授权文件、邮件或权利人许可页面的证据副本（在允许保存的范围内）。

## 7. 投诉、下架与撤回

- 提供权利人联系和投诉入口。
- 收到可信投诉后，先限制争议内容公开展示。
- 记录投诉、处理人、时间、证据和处置结论。
- 确认授权撤回或失效后，及时下架并停止媒体分发。
- 保留必要审计记录，同时遵守隐私和数据保留要求。

## 8. 儿童内容质量审核

审核作品是否适合网站的儿童文化定位：
- 内容是否准确、完整、来源可靠。
- 是否存在明显错误、歧视、恐吓或不适龄表达。
- 是否存在不安全行为的模仿风险。
- 适龄建议是否有明确编辑依据。
- 是否有清晰的语言、文化和历史背景说明。

## 9. 外链政策

- 优先链接权利人或官方平台页面。
- 不通过嵌入、代理或缓存规避平台限制。
- 定期检查链接状态。
- 外链页面的内容和播放行为由第三方控制，网站不宣称拥有其版权。

## 10. 复核

版权政策和来源许可应定期复核。授权到期、来源政策变化或收到权利人通知时，重新评估受影响内容。
