# 版权与内容审核政策

- 文档状态：Draft
- 版本：0.2

## 1. 目的

本政策支持平台以免费公共教育和传统文化传承为目标广泛建设资源目录，同时规范作品正文、翻译、歌词、图片、音频及外链的公开使用。它是产品和工程操作规范，不构成法律意见；存在疑问时应寻求专业法律意见。

## 2. 基本原则

- **目录先行、内容后审**：可合法发现的资源先建立基础目录、版本线索与合法来源链接，具体内容逐项评审后公开。
- 普及教育、公益或免费使用不自动改变第三方作品、译本、插画和录音的使用条件。
- 公开可访问不等于允许复制、存储或再发布。
- 作品进入公版不代表现代译本、注释、编曲、录音和插画也进入公版。
- 不同国家或地区的保护期限和例外规则可能不同。
- 每一种内容资产独立记录权利状态。
- 无法确认权利时，候选目录可在合规前提下公开必要的基础元数据和来源链接，但不公开正文或媒体。

## 3. 权利对象拆分

文学作品：
- 原作
- 翻译
- 改编
- 注释 / 赏析
- 插画 / 封面
- 朗读录音

歌曲：
- 词
- 曲 / 旋律
- 编曲
- 表演
- 录音制品
- MV / 视频
- 封面和宣传图片

古诗词：
- 古典原文
- 校勘版本
- 现代注释
- 白话译文
- 朗读录音
- 配图

## 4. 权利状态

| 状态 | 含义 | 默认公开策略 |
| --- | --- | --- |
| pending | 待评审 | 可公开基础目录与合法外链，不公开受保护正文或媒体 |
| public_domain_verified | 已核实公版 | 按核验地区及依据发布 |
| open_license | 开放许可 | 按许可证条件发布 |
| authorized | 已获得授权 | 严格按授权范围发布 |
| link_only | 仅允许外链 | 仅展示允许的元数据和链接 |
| restricted | 禁止公开使用 | 不公开相关内容 |
| expired_or_revoked | 授权失效或撤回 | 停止展示并按政策处理存储 |

## 5. 发布门禁

基础目录可在保留来源和「待评审」状态的前提下先行公开。正文、译文、插画、音频等具体内容公开发布前检查：
1. 作品身份和版本已确认。
2. 来源记录完整。
3. 正文、译文、图片、音频分别有权利记录。
4. 地域、用途、署名及有效期符合发布范围。
5. 内容审核通过。
6. 作品和媒体均未处于限制或撤销状态。

任何一项不满足时，不得通过公开 API 暴露相应受限内容。

## 6. 署名与许可证

- 按许可证要求展示作者、来源、许可证名称和链接。
- 对要求相同方式共享的许可，核实衍生内容是否满足条件。
- 对禁止商业使用或禁止演绎的许可，不得超范围使用。
- 保存授权文件、邮件或权利人许可页面的证据副本（在允许保存的范围内）。

## 7. 投诉、下架与撤回

- 提供权利人联系和投诉入口。
- 收到可信投诉后，先限制争议内容公开展示。
- 记录投诉、处理人、时间、证据和处置结论。
- 确认授权撤回或失效后，及时下架并停止媒体分发。
- 保留必要审计记录，同时遵守隐私和数据保留要求。

## 8. 儿童内容质量审核

审核作品是否适合网站的儿童文化定位：
- 内容是否准确、完整、来源可靠。
- 是否存在明显错误、歧视、恐吓或不适龄表达。
- 是否存在不安全行为的模仿风险。
- 适龄建议是否有明确编辑依据。
- 是否有清晰的语言、文化和历史背景说明。

## 9. 外链政策

- 优先链接权利人或官方平台页面。
- 不通过嵌入、代理或缓存规避平台限制。
- 定期检查链接状态。
- 外链页面的内容和播放行为由第三方控制，网站不宣称拥有其版权。

## 10. 复核

版权政策和来源许可应定期复核。授权到期、来源政策变化或收到权利人通知时，重新评估受影响内容。


## 11. 音乐播放资源的专项规则

音乐作品、具体录音/表演版本和平台播放资源必须分别建档、分别审核。至少区分歌词/词作、曲/旋律、译词/改编/编曲、表演、录音制品、MV/视频画面及封面等权利对象。

- 外部链接：优先指向权利人或官方平台页面；只保存必要元数据和链接，不下载或镜像平台音频/视频。
- 官方嵌入：平台提供 iframe 或站外播放器，只说明存在技术入口，不代表歌曲、录音或视频已获授权。启用前须核验具体资源权利、平台条款、站外播放许可及儿童内容适宜性。
- 站内托管：须确认作品及录音等全部相关权利允许目标地域、用途、期限和传播方式，或取得相应书面授权。
- 嵌入开关默认关闭。资源需经人工审核并记录审核日期、平台条款核验日期、原站链接和备用跳转链接。
- 不得通过代理、缓存、下载、去水印或其他方式规避平台限制；不得因 iframe 能加载就推断可以公开传播。
- 第三方播放器可能加载 Cookie、追踪技术、推荐内容或广告。上线前评估隐私告知、儿童体验和适用地区要求；默认不自动播放，关闭弹幕及非必要互动。
- 视频下架、授权到期/撤回、平台规则变化或出现不适龄内容时，应立即禁用对应播放资源；歌曲作品的基础资料可在合规范围内保留。

具体数据字段和实施阶段见 [音乐馆设计](MUSIC_LIBRARY_DESIGN.md)。
