# 信源清单与接入计划

- 文档状态：Research backlog
- 版本：0.1
- 重要说明：本文件是候选信源目录，不代表已完成授权审核或已实现采集器。

## 1. 信源评估字段

每个来源在启用前必须核实：
- 机构 / 网站名称及官方域名。
- 内容类型与语言。
- 是否提供官方 API、下载目录或 RSS。
- 服务条款、版权说明和再利用许可证。
- 是否允许自动访问及允许的频率。
- 可采集字段与禁止采集字段。
- 是否允许存储正文、翻译、图片或音频。
- 适用地域、署名要求及其他限制。
- 最近核验日期、核验人和证据链接。

## 2. 候选来源

| 来源 | 适用方向 | 首选方式 | 初步注意事项 |
| --- | --- | --- | --- |
| Project Gutenberg | 世界文学、公版书目 | 官方目录 / 数据下载 | 逐项核实作品及地域版权；遵守其自动访问政策 |
| Wikisource / 维基文库 | 古典文本、诗词、文献 | 开放接口 / 数据导出 | 每个页面和版本检查许可与来源 |
| Library of Congress | 文学、历史文化资料 | 官方 API | 按单项数字对象的权利说明判断 |
| Internet Archive | 书目发现、数字馆藏 | 官方 API | 可访问不等于可再发布；逐项检查权利与借阅限制 |
| 国家图书馆及公共文化机构 | 中文文学、古籍、文化资料 | 官方目录 / 开放接口 | 以具体资源的开放和授权说明为准 |
| 公开教育与文化机构 | 作品介绍、教育元数据 | 官方页面 / API | 优先采集元数据和链接，不默认复制正文 |
| 音乐平台官方页面 | 歌曲发现与索引 | 官方分享链接 / API（如获准） | 不下载或镜像平台录音、歌词 |
| 授权音乐目录 | 儿歌音频 | 官方 API / 下载 | 核实录音、词曲、编曲和地域授权 |
| 原创投稿 | 原创故事、儿歌 | 编辑后台 | 投稿者须明确授予网站所需权利 |

## 3. 官方入口（候选）

- Project Gutenberg: https://www.gutenberg.org/
- Gutenberg Catalog: https://www.gutenberg.org/ebooks/
- Wikisource: https://wikisource.org/
- Chinese Wikisource: https://zh.wikisource.org/
- Library of Congress: https://www.loc.gov/
- Internet Archive: https://archive.org/

这些入口仅用于信源发现。接入前仍须逐项检查官方 API 文档、访问政策和作品级权利说明。

## 4. 首批接入优先级

### P0：低风险目录与元数据
- 建立人工维护的经典作品目录。
- 导入已核验的公版书目元数据。
- 诗词目录先录入标题、作者、时代、出处和来源链接。
- 不因目录公开而自动复制完整正文。

### P1：开放文本与许可核验
- 选择权利说明清晰的单项作品。
- 保存许可类型、适用地域和证据。
- 通过测试用例验证署名与展示要求。

### P2：音乐索引与授权音频
- 先建立歌曲元数据和官方播放链接。
- 仅对授权音频开放站内播放。
- 单独记录词、曲、编曲、表演和录音的权利状态。

## 5. 来源接入审批模板

每新增一个 Adapter，提交以下信息：
1. 来源名称、官方 URL。
2. 官方 API / RSS / 数据集文档。
3. 服务条款与版权政策链接。
4. 允许采集的字段。
5. 请求速率及访问限制。
6. 允许保存的内容范围。
7. 允许公开展示的内容范围。
8. 署名和许可证要求。
9. 测试记录及最近复核日期。
10. 维护责任人。

未完成审批的来源保持 disabled。
