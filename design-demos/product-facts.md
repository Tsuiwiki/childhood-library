# 童年书房原型：事实与边界

- 项目仓库：`Tsuiwiki/childhood-library`，当前为 Phase 0 设计文档阶段，没有现成前端、设计系统或品牌资产。依据：`README.md` 的开发状态说明。
- 内容范围：儿童文学、经典儿歌、古诗词、英文儿歌。依据：`docs/PRD.md`。
- 产品原则：内容质量优先、来源可追溯、版权先行、人工审核后发布。
- 原型只使用作品名称、作者、时代等基础元数据和公版古诗短句作为演示，不虚构资源总量、用户评价、播放量或授权信息。
- 页面底部统一声明：「原型示例内容，正式发布前逐条核验来源与权利。」
- 外部视觉参考仅用于拆解版式，不复制其 Logo、插画或专有品牌资产。
- 参考网站已核实并查看真实截图：BookTrust 与 StoryWeaver，截图位于 `design-demos/refs/`。
